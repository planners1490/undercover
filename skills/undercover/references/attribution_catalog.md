### Human False-Positive Protection
- Standard human trailers (`Co-Authored-By: Jane Doe <jane@company.com>`, `Signed-off-by: ...`) are **never** stripped.
- Even ambiguous human first names (e.g., `Co-Authored-By: Claude Dupont <claude.dupont@corp.com>`) are preserved unless paired with a known AI domain/bot email or model qualifier (`Claude Code`, `Claude Opus`, `Claude Sonnet`, `Claude Haiku`).

## 2. PR, Issue & Commit Footers

- `🤖 Generated with [Claude Code](https://claude.com/claude-code)`
- `Generated with [Claude Code](https://claude.ai/code)`
- `*_Generated with Cursor_*`, `Powered by ...`, `Created by Devin`
- HTML comments: `<!-- Generated by Claude Code -->`
- Self-disclosure phrases: `As an AI language model`, `Written by an AI`, plus any user-defined confidential project codenames or internal URLs registered via `init-policy --blocked-terms` (or `UNDERCOVER_BLOCKED_TERMS`).
- Trailing horizontal dividers (`---`) immediately above a stripped PR footer are also collapsed cleanly.

## 4. Invisible Unicode Watermarks

| Category | Codepoints | Severity | Action in `clean-unicode` |
| :--- | :--- | :--- | :--- |
| **Unicode Tags** | `U+E0000`–`U+E007F` | `CRITICAL` | Remove (virtually exclusive to steganographic text watermarking) |
| **Zero-Width Formatters** | `U+200B`, `U+200C`, `U+200D`, `U+2060`–`U+2064`, `U+00AD`, `U+180E`, mid-file `U+FEFF` | `HIGH` | Remove (automatically preserves emoji ZWJ sequences and Arabic/Persian/Indic ZWNJ/ZWJ) |
| **Bidi Overrides (Trojan Source)** | `U+202A`–`U+202E`, `U+2066`–`U+2069`, stray `U+200E`/`U+200F`/`U+061C` | `HIGH` | Remove outside RTL scripts |
| **Variation Selectors Supplement** | `U+E0100`–`U+E01EF` | `HIGH` | Remove (preserves genuine CJK Ideographic Variation Sequences) |
| **Exotic Typographic Spaces** | `U+202F` (NNBSP), `U+2000`–`U+200A`, `U+205F`, `U+00A0` (in code) | `MEDIUM` | Normalize to standard ASCII space (`0x20`) |
| **Leading UTF-8 BOM** | `U+FEFF` at byte 0 | `INFO` | Preserved by default (strip only with `--strip-bom`) |
